# Projeto: Pedra, Papel e Tesoura

**1. Nome do projeto**

Pedra, Papel e Tesoura.

**2. Descrição do que o projeto faz**

O projeto consiste em um jogo interativo de Pedra, Papel e Tesoura, no qual o usuário pode jogar contra o computador.

O jogador escolhe uma das três opções disponíveis: Pedra, Papel ou Tesoura. Em seguida, o computador realiza uma escolha aleatória e o sistema compara as duas jogadas para determinar o resultado da partida, que pode ser vitória, derrota ou empate.

O resultado é exibido na tela, mostrando a escolha do jogador, a escolha do computador e quem venceu a rodada.

**3. Tecnologias utilizadas**

- **HTML5:** utilizado para estruturar o conteúdo da página e os elementos do jogo.
- **CSS3:** utilizado para estilizar a interface, aplicar cores, gradientes, organizar os botões e criar efeitos visuais.
- **JavaScript:** utilizado para desenvolver a lógica do jogo, identificar as escolhas do jogador, gerar escolhas aleatórias para o computador e determinar o resultado da partida.

**4. Orientações de como executar ou visualizar o projeto**

Para executar o projeto, siga os passos abaixo:

1. Baixe os três arquivos do projeto: `Index.html`, `style.css` e `script.js`.
2. Salve os três arquivos dentro da mesma pasta.
3. Abra o arquivo `Index.html` em um navegador de internet, como Google Chrome, Microsoft Edge ou Firefox.
4. A página do jogo será aberta e estará pronta para utilização.
5. Clique em uma das opções (Pedra, Papel ou Tesoura) para jogar contra o computador e visualizar o resultado.

Não é necessário instalar programas adicionais ou utilizar conexão com a internet para executar o jogo.
